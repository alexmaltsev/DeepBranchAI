# External Transfer Protocol

## Study Design

Each external dataset used paired images and reference labels with fixed five-fold splits. Scratch nnU-Net and DeepBranchAI-pretrained models used the same target folds within each dataset.

| Dataset | Volumes | Target |
|---|---:|---|
| 3D-IRCADb | 12 | Abdominal venous system in CT |
| Plant CT | 29 | Plant root systems in CT |
| AeroPath | 27 | Pulmonary airway trees in CT |

The nnU-Net experiments used nnU-Net v2 preprocessing and planning, including dataset-specific resampling, normalization, patch selection, default augmentation, CE + Dice loss, and a 100-epoch `nnUNetTrainer` schedule. Optimization used stochastic gradient descent with Nesterov momentum (`0.99`), weight decay `3e-5`, and polynomial learning-rate decay from `0.01`.

Scratch models used random initialization. DeepBranchAI-pretrained models were initialized from the released fold-0 mitochondrial checkpoint, and all weights were updated during target-domain fine-tuning. This evaluates supervised transfer, not zero-shot segmentation.

## Comparator Protocols

All comparator rows were generated by the authors on the same target-dataset folds and assessed with the same volume-wise metric code. Each comparator retained its native training procedure.

### VesselFM

- Public foundation checkpoint adapted to 3D-IRCADb venous CT.
- Full fine-tuning of all 31.4 million parameters.
- 10,000 optimizer steps.
- DiceCE loss weighted `0.9` Dice and `0.1` cross-entropy.
- AdamW, initial learning rate `1e-5`, weight decay `0.1`.
- Cosine annealing to `1e-7`.

VesselFM retained its native step-based budget and was not strictly epoch-matched to the 100-epoch models. Upstream reference: [Wittmann et al., vesselFM](https://doi.org/10.48550/arXiv.2411.17386).

### Plant Root 3D U-Net

- Custom four-level PyTorch 3D U-Net trained from random initialization.
- Full update of all model weights for 100 epochs.
- BCE-with-logits plus soft Dice loss.
- AdamW, initial learning rate `0.001`, weight decay `1e-5`, constant learning rate.
- Source implementation: [`train/comparators/plant_root_3d_unet/`](../train/comparators/plant_root_3d_unet/).

The comparator was informed by prior root-system 3D U-Net work, not a MONAI-provided model. Dataset: [Harwood, Plant root segmentation training data](https://doi.org/10.5281/zenodo.14189395).

### MurineAirwaySegmentation

- Airway-specific, cross-modality checkpoint adapted to AeroPath CT.
- Public Task145 fold-0 checkpoint fully fine-tuned for 100 epochs on every AeroPath fold.
- Dice plus cross-entropy loss.
- Stochastic gradient descent with Nesterov momentum, initial learning rate `0.01`, momentum `0.99`, weight decay `3e-5`, and polynomial decay.

Checkpoint: [MurineAirwaySegmentation weights](https://doi.org/10.5281/zenodo.7892040). Target dataset: [AeroPath](https://doi.org/10.1371/journal.pone.0311416).

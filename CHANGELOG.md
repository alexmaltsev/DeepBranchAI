# Changelog

## 1.0.0 - 2026-09-01

Publication release aligned with the accepted manuscript, *DeepBranchAI: a transferable 3D segmentation model for branching networks*.

- Reframed the repository around the released transferable 3D checkpoint.
- Added all five mitochondrial checkpoint links and fold-selectable downloads.
- Added accepted manuscript Tables 2-6 in machine-readable form.
- Added full-volume mitochondrial metrics, paired external-transfer measurements, statistical analysis, and result validation.
- Added the final external-transfer qualitative figure and its source masks.
- Added model-card, reproducibility, transfer-protocol, citation, packaging, and CI metadata.
- Documented the VESSEL12 checkpoint, training archive, and notebooks alongside the external-transfer resources.
